二、原有 Bug 及防御性修复
══════════════════════════════════════════════════════════════════

1. free_options() 在 hidden input 上报 TypeError
   - free_options(document.form.rt_wep_x) 在 WEP 选项被移除后
     rt_wep_x 变成 <input type=hidden>, 没有 .options 属性
     → 原代码: selectObj.options.length → undefined.length → 报错
   - 连锁导致 change_wep_type 报错 → wl_auth_mode_change 中断
     → wl_wep_change / rt_wep_change 从未完整执行过
   - 修复: free_options 加 options==null 检查; change_wep_type
     开头加 hidden input 提前返回分支

2. change_key_des() 未定义
   - 只在 device-map/router*.asp 中定义
   - wireless.js/2g.js 的 wl_wep_change 末尾无条件调用
   - 原来被 Bug 1 的 TypeError 掩盖了 (还没执行到这里就报错)
   - 修复: typeof(change_key_des) == 'function' 检查

3. set_display / inputCtrl null 安全
   - 许多页面没有 row_wpa3 / row_wep1-7 / row_protect 元素
   - 原代码直接 $("row_xxx").style.display → 找不到元素时报错
   - 修复: 加 null 检查
